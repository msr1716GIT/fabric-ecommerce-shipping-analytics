# Source Data

## Dataset

**Dataset Name:** E-Commerce Shipping Data

**Source:** Kaggle

**File Format:** CSV

**Records:** Approximately 11,000

**Columns:** 12

**File Size:** 430 KB

**Primary Domain:** E-Commerce Logistics and Shipping Performance

---

## Dataset Description

The dataset contains shipping and fulfillment information for customer orders, including shipment methods, warehouse locations, product information, customer ratings, discounts, delivery outcomes, and other operational attributes.

The data is already organized in a denormalized analytical structure, making it well suited for a streamlined reporting solution without requiring extensive dimensional modeling.

---

## Purpose

This dataset was selected to demonstrate an end-to-end Microsoft Fabric solution that covers data ingestion, transformation, business rule implementation, incremental loading, semantic modeling, and Power BI reporting.
