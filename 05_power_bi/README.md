# Power BI

This folder contains the final reporting deliverables for the End-to-End E-Commerce Shipping Analytics project.

## Deliverables

| File | Description |
|------|-------------|
| dashboard.png | Executive Fulfillment & Operations Dashboard built in Power BI. |
| semantic_model.png | Semantic Model used for reporting, including the Gold reporting table and DAX measures. |

## Dashboard Highlights

- Executive KPI summary
- Shipping performance monitoring
- Delivery status analysis
- Warehouse performance analysis
- Discount strategy distribution
- Interactive filtering by Warehouse Block and Product Importance

The report is powered by a Microsoft Fabric Semantic Model operating in Direct Lake mode using data from the Gold reporting table.
