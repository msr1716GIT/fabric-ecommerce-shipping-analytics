# Dataset

This project uses the **E-Commerce Shipping Data** dataset obtained from Kaggle. The dataset contains historical shipping records that capture different aspects of the order fulfillment process, including customer information, shipping methods, warehouse locations, product importance, discounts, customer ratings, and delivery outcomes.

The dataset is already organized as a single analytical dataset, making it suitable for reporting and analytics without requiring a traditional dimensional model. Instead of redesigning the data into multiple dimensions and fact tables, this project preserves the existing structure and prepares it for business reporting through data validation, standardization, and business rule implementation.

## Dataset Summary

| Item | Description |
|------|-------------|
| **Source** | Kaggle – E-Commerce Shipping Data |
| **File Format** | CSV |
| **Business Domain** | E-Commerce Logistics & Shipping |
| **Primary Subject** | Shipping Performance & Delivery Outcomes |
| **Data Structure** | Single Denormalized Analytical Dataset |
| **Target Data Model** | Single Denormalized Gold Fact Table |
| **Primary Key** | ID |

The dataset supports analysis of:

- Shipping performance
- Delivery status
- Warehouse operations
- Shipping methods
- Product importance
- Discount strategies
- Customer ratings
- Customer purchasing behavior
